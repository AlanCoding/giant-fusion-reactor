# Numerical Model Archive

These directories preserve superseded model families. An archive records what
was calculated and why it was retired; it is not an alternative active
architecture.

| Archive | Boundary |
|---|---|
| `n14-uniform-seed-0d` | Early uniform-heating and front screens |
| `tofel-0d-2026-09-04` | D-T-pushed six-shot and grouped-event calculations |
| `n15-pre-layered-2026-09-06` | Early N15 secondary-pusher models |
| `n15-single-stage-layered-v0.4` | First explicit pressure-driver/tamper reference |
| `n15-complete-layered-v0.5` | Last three-implosion complete-cycle reference before Roman |

Large generated CSV files from the pre-Roman work have been moved into local
`generated/` subdirectories and remain ignored by Git. Stable reports,
reference inputs, small summary tables, and reproduction commands are tracked.
Git history remains the authoritative source for exact earlier source trees.
